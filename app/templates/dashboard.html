Demo Program Flow

1. Upload

Workbook AC dan SR masuk ke storage job lokal.

2. Queue + Worker

Job masuk `Waiting Queue`, lalu worker ubah ke `Processing` dan menjalankan pipeline.

3. Validation + Journaling

Sistem cek mismatch, partner balance, dan warning jurnal di tiga stage simulasi.

4. Result Review

UI menampilkan review notes, file output per partner, log validation, dan ZIP archive.
